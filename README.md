# Fina Calle Landing

Premium, mobile-first landing page for **Fina Calle by AMMA Ventures LLC**.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Notes

- Static landing page only.
- No backend.
- No auth.
- No payment processing.
- No secrets or environment files required.
